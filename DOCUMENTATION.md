# LustraHair - Luxury Hair Salon Template

Thank you for purchasing LustraHair.

LustraHair is a premium React + Tailwind CSS template designed for hair salons, beauty studios, and hairstylists.

---

# Requirements

Node.js 18+
npm or yarn

---

# Installation

1. Download the template
2. Extract the files
3. Open the project folder in your code editor

Install dependencies:

npm install

Run development server:

npm run dev

Build production version:

npm run build

# Customization

Main customization areas:

Brand colors:
tailwind.config.js

Images:
/assets

Text content:
/pages and /components

---

# Changing Images

Replace Unsplash placeholder images with your own images.

Example:

<img src="/assets/your-image.jpg" />

---

# WhatsApp Button

To update WhatsApp number edit:

components/WhatsAppButton.jsx

Replace:

https://wa.me/2340000000000

with your own number.
